# planning/

Active and future work. Read this first when planning a new task; updated as work moves.

Planning lives in three layers:

1. **The V1 sprint** — [milestones.md](milestones.md) (M1–M11): the one-time scaffolding build-out to a usable, shippable V1. It has an *end* (M11). [walking-skeleton.md](walking-skeleton.md) is M1 in detail.
2. **The status log** — [current-focus.md](current-focus.md): what's in flight and what just shipped.
3. **The post-V1 backlog** — the numbered `NNNN_` specs: enhancements and follow-ups that build *on top of* the V1 foundation, not new milestones. Some were deferred out of a milestone (`0003`/`0004` from M8); others are fresh ideas. (The **Open items** at the bottom are a looser holding area for post-V1 ideas.)

## Groupings — items that could share a PR

Several backlog items compose (surfaced by the 2026-07-06 UX review):

- **The feedback layer** — [0002](0002_recording-indicator-hud.md) (the HUD, the visual anchor), [0004](0004_model-loading-indicator.md), [0016](0016_recording-sound-cues.md), [0018](0018_transient-error-toasts.md), and [0020](0020_mic-level-meter.md) are all additional observers of the same `AppState` seam ([../architecture/app-state-and-menu-bar.md](../architecture/app-state-and-menu-bar.md)) — no architectural change, purely additive renderers. [0018](0018_transient-error-toasts.md) and [0020](0020_mic-level-meter.md) render *inside* the 0002 panel, so those three are natural to land as a single PR; [0004](0004_model-loading-indicator.md) and [0016](0016_recording-sound-cues.md) are independent riders of the same seam and can land separately in any order.
- **The model pipeline pair** — [0004](0004_model-loading-indicator.md) before [0021](0021_model-picker.md): the picker's model switch re-enters exactly the download/load window 0004 makes visible.
- **The transcription-quality set** (surfaced by the 2026-07-06 transcription-quality review) — [0022](0022_transcription-eval-harness.md) is the instrument, [0021](0021_model-picker.md) and [0023](0023_silence-decoding-hardening.md) are the consumers. Ordering: 0022 before 0021 (the scorecards decide the curated list and default — possibly just a default bump ahead of any picker UI); [0023](0023_silence-decoding-hardening.md) is independent and model-agnostic and can land first, but its threshold choices are verified against 0022's silence fixtures. The set's shared posture, on record in [0008](0008_custom-dictionary-redesign.md)'s drop notice: off-the-shelf models as-is — no dictionaries, glossaries, or personalization layers.
- **Standalone** — [0012](0012_onboarding-permissions-polish.md), [0017](0017_cancel-recording.md), [0019](0019_last-transcript-recovery.md), [0003](0003_pause-media-while-dictating.md) have no ordering dependencies among the above.

## Open items / TODOs

These are tracked here until they're picked up into an active milestone or moved to `requirements/`:

- **Settings UI for Fn key warning**: parallel to the existing Caps Lock + Hold warning.
- **Prominent live-reconfiguration notice**: M9 surfaces the "new key now stops the recording" message in the menu dropdown; an always-visible version rides the recording HUD ([0002_recording-indicator-hud.md](0002_recording-indicator-hud.md)).
- **Model picker in Settings**: promoted to [0021_model-picker.md](0021_model-picker.md) (2026-07-06).
- **From the 2026-09-28 performance and size review** (the five fixes it produced are in [current-focus.md](current-focus.md)):
  - *A rare crash path.* swift-transformers' `Hub` resource bundle is not in River.app, and its `Bundle.module` accessor calls `fatalError` when the bundle is missing. It runs only when a model has `config.json` but no usable tokenizer config. Copying the bundle into `Contents/Resources` won't help: the accessor looks only at the `.app` root, where code signing forbids loose files.
  - *No Accessibility timeout.* The focused-element read before typing runs on the main thread with the system's ~6 s default; set a short `AXUIElementSetMessagingTimeout`.
  - *Decode settings.* Timestamps are decoded but unused (`withoutTimestamps`), and `temperatureFallbackCount` 5 allows six passes on unclear audio; tune with [0022](0022_transcription-eval-harness.md).
  - *Panel re-renders.* `RiverIndicatorView` reads `inputLevel` at its root, so the whole panel re-evaluates on every level update although the mark redraws each frame anyway.
  - *Wrong cue on silence.* An all-silent recording plays the cancel cue: `SoundFeedbackController` infers transitions from state snapshots and misses a `.processing` passed through in one turn.
  - *Model cleanup.* [0021](0021_model-picker.md) chose to keep switched-away models assuming 240–630 MB each; they are 150 MB to 1.6 GB. Revisit with the real sizes.
  - *Default model on 8 GB Macs.* `small.en` holds about 480 MB in Neural Engine memory, which Activity Monitor does not show. A product decision.
  - *WhisperKit version floor.* `from: "0.9.0"` resolves to 0.18.0; raise the floor to what is tested.
  - *Deepening candidates.* Put Whisper's input rules (convert, trim, pad, "nothing said") in one transcription module; give one module ownership of the model's lifetime (first load, switch, retry, cached offline load), where [ADR 0001](../decisions/0001-defer-cycle-protocol-seams.md)'s revisit condition ("cycle tests start needing to inject success-path scenarios") is now met by `transcribeResultForTesting`, so add the seam or amend the ADR on purpose; one pure function for what the panel shows; deliver cycle transitions to observers as events.
  - *Loose ends.* `RiverSession` stores `inputMonitoring` but never uses it; `MicrophoneCapability.inputFormat` is written but never read; comments in `AccessibilityCapability` still mention ⌘V and the clipboard.
  - *Docs over ~150 lines.* `architecture/release-pipeline.md`, `conventions/local-builds.md`, and `conventions/tests.md` need a split in a docs pass.
  - *Sparkle update test.* Verify on `v0.2.1-rc1` that a user-defaults `SUFeedURL` points an installed rc at the next rc's appcast, then record the procedure in [release-pipeline.md](../architecture/release-pipeline.md) "Test runs".
- **Rename `TranscriptionService` → `TranscriptionManager`**: *done (2026-08-01, PR #24)* — aligned with the `Manager` suffix convention for cycle collaborators (see [../conventions/swift-style.md](../conventions/swift-style.md)). Kept for historical context.
- **macOS 16 pasteboard privacy**: *still moot, for a narrower reason than [0011](0011_keystroke-injection.md) originally gave* — Apple is rolling out prompts for programmatic pasteboard **reads** (preview in macOS 15.4; enforcement expected in macOS 16). 0011 made insertion keystroke-based, so River never *reads* the pasteboard and the prompt can't trigger. The "nor writes" half of that claim no longer holds: [0019](0019_last-transcript-recovery.md) reintroduced a single user-invoked write (`copyLastTranscript`, carrying the nspasteboard.org marker types). A write is not a read, so the conclusion is unchanged — but the reasoning now rests on read-vs-write rather than on touching the pasteboard at all.
